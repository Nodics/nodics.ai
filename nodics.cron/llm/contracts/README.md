# nodics.cron Contracts

This folder contains Cron-specific AI/developer contracts.

Use root `AGENTS.md`, `nodics.cron/AGENTS.md`, and
`nodics.foundation/modules/nSetup/llm/contracts` as the primary authority. Add a
contract here only when `nodics.cron` introduces a durable scheduled-job,
runtime ownership, node responsibility, execution lifecycle, or customization
rule that is more specific than the shared framework contracts.
