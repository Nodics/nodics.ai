# Order

Order is its named Commerce capability boundary. Reusable contracts and behavior belong to this named capability boundary. Archived gComm is reference-only.

Customer manual reviews follow [the purchase review contract](llm/contracts/manual-purchase-review-contract.md).

Generic reverse requests prove submission only and remain blocked before owner
effects. The independently enabled, Store-scoped guarded refund path can select
Fulfillment's reviewed full-order physical cancellation/return bridge. Existing
partial or uncertain effects require original-command reconciliation, not another
stock change. Refunds require the independently enabled, scoped guarded path;
staff recovery previews retain the original case-bound approval command reference.
Missing references or another case cannot initiate replacement commands;
see [reverse execution safety](llm/contracts/manual-purchase-review-contract.md#reverse-execution-safety).

The shared processor requires confirmed owner outcomes and original-command-bound
replay evidence. Pending or ambiguous results stop subsequent owners and retain
reconciliation checkpoints; they cannot be reported as completed reversals.

Operator actions return a confirmed persisted lifecycle request, not a database
write acknowledgment. Stale revisions and unconfirmed readback require
reread/reconciliation. Retrying an unchanged blocked action preserves its revision.

This capability declares an inert model-service inventory for [governed Local reset](../../../../../nodics.foundation/modules/nSystem/llm/contracts/local-reset.md).
A server must explicitly select it; contributions never enable reset or bypass tenant, environment, confirmation or required-service checks.

Route-category defaults belong to this capability; deployments supply only intentional overrides.
Preserve nRouter enforcement and independent route authorization. See [exposure ownership](../../../../../nodics.foundation/modules/nRouter/llm/contracts/README.md#capability-owned-exposure-defaults).
