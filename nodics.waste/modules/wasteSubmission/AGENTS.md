# wasteSubmission Agents

Follow the parent contract: `../../AGENTS.md`.
Follow global guidance: `../../../nodics.foundation/modules/nSetup/llm/ai-enablement-index.md`.

`wasteSubmission` owns generic submission, evidence-link, metadata suggestion,
and submitter-confirmation lifecycle. It must not create reward records or raw
media assets.

Image-source concerns are advisory classification with a mandatory manual
approval hold. A depicted supported item can continue to review; promotional,
illustrated, screenshot, suspected synthetic and uncertain evidence must never
be silently promoted to a direct item photograph. Preserve holds across
reanalysis and photo replacement and delegate final decisions to Verification.

This capability declares an inert model-service inventory for [governed Local reset](../../../nodics.foundation/modules/nSystem/llm/contracts/local-reset.md).
A server must explicitly select it; contributions never enable reset or bypass tenant, environment, confirmation or required-service checks.
