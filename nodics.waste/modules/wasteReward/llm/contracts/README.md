# Waste Reward Contracts

Waste Reward stores immutable reward-calculation evidence for Waste submissions/assets.

Assessment types:
- ESTIMATED — pre-approval calculation from best eligible metadata.
- CONFIRMED — fresh calculation from verified facts.
- RECALCULATED — later confirmed-fact recalculation.

Never replace an ESTIMATED record with a CONFIRMED record. Persist exact Rules policy, band-set and property-catalogue versions plus explanation evidence.

The authorized [material-value extension](material-value.md) adds separate immutable financial allocation evidence and a narrow Loyalty release coordinator. Participation score bands, approval settlement flags and asset ownership are not payment or material-value entitlement authorities.
