Follow the parent contract: `../../AGENTS.md`.

`wasteMaterial` owns reusable waste families, categories, item types, material
types, condition grades, evidence policy, and generic impact policy references.
Partner projects may extend taxonomy through seed data and later-layer schema
extensions.

This capability declares an inert model-service inventory for [governed Local reset](../../../nodics.foundation/modules/nSystem/llm/contracts/local-reset.md).
A server must explicitly select it; contributions never enable reset or bypass tenant, environment, confirmation or required-service checks.

Metadata changes must preserve the [property coverage and lifecycle contract](llm/contracts/README.md) and its focused persistence/projection regressions.
