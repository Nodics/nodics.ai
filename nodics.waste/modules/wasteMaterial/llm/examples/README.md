# wasteMaterial Examples

Examples should show generic taxonomy records and accelerator/project taxonomy
extensions.

A readable device with an unreadable label retains material/range observations
while brand/model stay unknown. A promotional depiction retains item identity
with a manual hold and unknown physical ranges. A sparse legacy record projects
all dimension axes with null endpoints. A reviewed record uses reviewer facts;
a rejected item cannot confirm a reward estimate. A later descriptor policy
`minimumFieldConfidence: 0.4` changes reporting only, never approval rules.
See the recognition alignment and descriptor contract tests for executable cases.
