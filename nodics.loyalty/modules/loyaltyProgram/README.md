# Loyalty Program

`loyaltyProgram` defines program-level contracts such as program code, status, earning/spending enablement, and default reward type.

Native Super Admins manage partner conversion eligibility through the targeted
Loyalty API read/update commands. Program owns fresh authority, revision CAS and
last-change audit; generic schema routing remains disabled. See
[operator and adoption details](llm/contracts/partner-eligibility-administration.md).

This capability contributes an inert model-service inventory for [governed Local reset](../../../nodics.foundation/modules/nSystem/llm/contracts/local-reset.md).
Deployment selection, environment and tenant checks, confirmation and required services remain mandatory.
