# mockProvider

Deterministic in-process Copilot provider adapter for contract tests.

This adapter contributes deterministic, credential-free, in-process responses
for provider gateway and orchestration tests. It is not a production model and
owns no provider selection or business policy.

For implementation rules, read this module `AGENTS.md` after the root-to-leaf ancestor `AGENTS.md` chain. For exact contracts and examples, read this module `llm/` guidance and the relevant global contracts under `modules/nSetup/llm`.
