# installer Examples

Examples in this folder are scoped to installed-runtime Application Builder
operations.

Reserved examples may cover safe status output, preflight summaries, support
bundle summaries, and Axis-facing operation metadata. Do not include executable
frontend code or commands that mutate a customer workspace without the matching
backend API contract.

Select only a deployment-specific `installer.applicationBuilder.workspace.allowedRoots` value. A customer/environment can select its own project root through the existing `$config: path` binding. Inherit all limits, planning defaults, copy and vendor protections. Refresh owner availability, submit a read-only plan, inspect its dependencies, and keep application creation explicitly unavailable. Run owner and Axis regressions; do not create or modify a project through a shell to imitate an API receipt.
