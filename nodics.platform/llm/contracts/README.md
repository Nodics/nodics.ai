# nodics.platform Contracts

This folder contains Platform-specific AI/developer contracts.

Use root `AGENTS.md`, `nodics.platform/AGENTS.md`, and
`nodics.core/modules/nSetup/llm/contracts` as the primary authority. Add a
local contract only when Platform introduces durable rules for Profile,
BackOffice, Axis backend support, module registration, capability discovery,
security, or API governance that are more specific than shared framework
contracts.
