# media Contracts

This index routes developers to Media's storage, preparation, retained publication and readiness contracts.

The [governed library and publication initiation contract](media-library-publication.md)
defines safe current-version reads and existing Axis backend-operations workspaces
without enabling schema APIs or replacing nPublish approval authority.

Media owns governed bytes, provider selection and references. Do not accept client paths, duplicate storage or expose private provider details. Retained publication and installed-provider qualification remain explicitly gated.

Detailed material is preserved in the adjacent [contract guide](media-lifecycle-contracts.md). This README is the discovery index, not a replacement authority or evidence that runtime qualification passed.

Read [owner guidance](../../AGENTS.md) before changing behavior. Customize through the established later-loaded configuration, services, providers, schemas and runtime layers described in the guide; do not copy framework owners or bypass their invariants. Verification commands and their limits are retained in the guide. This documentation-only reorganization runs no behavioral tests or operations.
