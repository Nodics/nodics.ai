# eWaste contracts

The [e-waste domain contract](e-waste-domain.md) defines capability ownership,
customer journeys, channel account entry, catalogue/detail access, settlement,
and the optional WARM impact adapter. Follow the module `AGENTS.md` first.

The [common bundle Commerce contract](common-bundle-commerce.md) governs new
listing/gift/purchase callers, exact public projections and test migration.
The [one-asset contract](digital-ownership-sale.md) retains historical evidence
and recovery context only; it does not admit new legacy sales or completed returns.
