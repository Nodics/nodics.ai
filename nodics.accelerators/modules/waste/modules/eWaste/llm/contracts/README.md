# eWaste Contracts

- eWaste values must be data-driven records targeting `nodics.waste` schemas.
- eWaste must not duplicate common Waste schemas, lifecycles, APIs, or services.
- eWaste must not own partner project policy, rewards, coupons, maps, providers,
  or certification claims.
- Partner projects extend eWaste through later seed packs, policy modules, and
  integration adapters.
- `Nodics Circa` is the reusable customer-facing e-waste/circular-asset
  application contract. Follow `circa-application.md` when defining Circa flows,
  policy defaults, or application boundaries.
- Follow `circa-reusable-backlog.md` for the reusable 52-action roadmap before
  implementing Circa-backed asset, wallet, marketplace, coupon, or governance
  behavior.
