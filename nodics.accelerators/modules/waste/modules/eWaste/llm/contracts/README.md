# eWaste contracts

The [e-waste domain contract](e-waste-domain.md) defines capability ownership,
customer journeys, channel account entry, catalogue/detail access, settlement,
and the optional WARM impact adapter. Follow the module `AGENTS.md` first.

The [persisted digital asset sale owner contract](digital-ownership-sale.md)
defines the optional disabled/unqualified one-asset Loyalty path through
DigitalCore and persisted Waste: sequence, exact policy/binding/capture evidence,
seller-only credit, cancellation/recovery and unsupported refund/custody modes.
