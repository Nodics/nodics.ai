# eWaste

`eWaste` is the electronic-waste scenario accelerator for Nodics Waste
Management. It packages reusable e-waste taxonomy, evidence, collection, and
impact presets as seed data for `nodics.waste`.

The reusable customer-facing e-waste and circular-asset application name is
**Nodics Circa**. Circa composes eWaste submissions, photo evidence, approved
customer-owned assets, reward/carbon wallet projections, marketplace/gift flows,
and coupon marketplace journeys through reusable framework contracts.

Partner projects consume these presets and add their own accepted-item policy,
reward formula, release trigger, customer journey, branding, location/map
configuration, provider adapters, vendor/coupon integration, and country-specific
compliance rules.
