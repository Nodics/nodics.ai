`circa.eWaste` owns reusable backend application composition for Nodics Circa.
It may orchestrate customer e-waste use cases across `nodics.waste`, `eWaste`,
`wasteRecycling`, Wallet/Loyalty, Commerce/Product, Promotion/Coupon, Media,
Location, and Profile by references and existing API operations.

Do not create `circaEWasteSubmission`, `circaEWasteAsset`, wallet ledger,
Commerce product, coupon entitlement, media file, location provider, recycler
adapter, or project branding authorities here. Those capabilities stay with
their owning framework, scenario accelerator, provider module, frontend module,
or project layer.
