# Waste Recycling

`wasteRecycling` is the reusable recycling handoff accelerator above
`nodics.waste`.

It defines contracts for connecting approved customer-owned waste assets and
`DONATE` transfer events to movement/compliance records and project-owned
recycler or logistics integrations.

It does not own provider credentials, adapter implementations, tracking numbers,
certificates, wallet ledgers, customer journeys, or partner commercial policy.
Partner projects bind concrete providers and callback handling in project modules
or later provider accelerators.
