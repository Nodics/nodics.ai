# Nexus Core

`nexusCore` supplies inert Nexus initialization and acceptance descriptors. Platform can select this capability without activating WCMS or importing content. The existing BackOffice and nImport owners execute governed operations only on authorized requests.

The independent `nodics.nexus` frontend owns rendering. Customers extend the accelerator in their own modules and override Site, catalog, publication and deployment choices through existing layers. Configuration does not install or publish content.
