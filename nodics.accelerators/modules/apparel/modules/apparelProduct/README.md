# Apparel Product

`apparelProduct` contributes reusable Apparel semantics to the standard
Commerce Product authority. Product retains product, category, variant/SKU,
brand identity, localization, publication, and base search-projection
ownership. This module will own only Apparel-specific structures and behavior
such as style, colourway, size systems, fit, material, season, collection, and
Apparel brand profile.

The current WP-1A boundary is structural only. No Apparel schema or behavior is
implemented until the scaffold discovery and activation contract passes.
