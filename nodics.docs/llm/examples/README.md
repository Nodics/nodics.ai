# nodics.docs Examples

This folder contains examples for framework documentation content ownership,
content-pack generation, release validation, and CMS import projection.

Examples must keep authored framework documentation in `nodics.docs` and must
not move backend-importable records into frontend repositories.

For a framework product guide, follow `docs/pages/accelerators/circa-overview.md`
and its six linked topics: explain users/outcomes, owner records and configuration,
screen/API flow, rejected/boundary/recovery behavior, worked custom project files,
preserved invariants and separate acceptance gates. Add stable catalogue metadata,
source evidence and public navigation; regenerate the CMS release instead of editing
generated records. This structure is reusable for Agora without copying Circa facts.
