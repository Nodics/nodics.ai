# testimonial Examples

## Supported customization direction

A project can add a testimonial placement policy, but consent withdrawal must remain authoritative and remove every active projection.

An approved version can produce separate WEB/AE and APP/AE projections only when the consent explicitly includes both channels and the region. The public projection contains sanitized editorial text, approved attribution, and required material-relationship disclosure; it never copies provenance evidence.

## Rejected shortcut

Do not overwrite original wording, infer consent across channels or regions, treat WCMS placement as testimonial authority, expose schema CRUD directly, or allow asynchronous cleanup to be the only response to consent withdrawal.
